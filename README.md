# CCNA 200-301 Practice Quiz

Interactive practice quiz: 1,401 questions (multiple choice, drag and drop, lab simulations) with the correct answer and a reason shown after each submission. Progress is saved in the browser.

## Publish with GitHub Pages

1. Repository **Settings > Pages**.
2. Source: **Deploy from a branch**, branch **main**, folder **/ (root)**.
3. Open `https://dularaabhiranda.github.io/xCCNA/` after the build finishes.

## Files

- `index.html` - the quiz page
- `data.js` - questions, answers and explanations
- `pix/` - exhibit images, loaded on demand
